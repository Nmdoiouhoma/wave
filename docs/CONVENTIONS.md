# Wave — Conventions

Binding for every agent. Contract = `openapi.yaml`; schema = `DATA_MODEL.md`. Deviations go through architect.

## 1. Repository layout

```
backend/   Symfony 7.4 app (backend; src/Media + src/DataFixtures = media-infra)
frontend/  React app (frontend)
infra/     nginx, php ini/fpm pools, minio init, Dockerfiles (media-infra)
docs/      architect (SECURITY.md = qa-security)
compose.yaml  Makefile  .env.example   (media-infra)
```

## 2. Backend (PHP)

- `declare(strict_types=1);` everywhere, `final` by default, `readonly` for DTOs/messages/value objects. PSR-12 via PHP-CS-Fixer (`@Symfony` + `@PHP84Migration`). PHPStan level 8, no baseline growth.
- Namespaces (`App\` = `backend/src/`):

| Dir | Content | Owner |
|---|---|---|
| `Entity/`, `Repository/` | Doctrine entities + repositories (custom queries, keyset helpers) | backend |
| `Enum/` | Backed enums of DATA_MODEL §1 | backend |
| `ApiResource/` | **API Platform resources = output DTOs** (`TrackView`, `PostView`…) with operations declared on them. Entities are **never** exposed as API resources. | backend |
| `Dto/Input/` | Input DTOs (`CreatePlaylistInput`…) with Validator constraints | backend |
| `State/Provider/`, `State/Processor/` | One provider/processor per operation family (`TrackProvider`, `UploadTrackProcessor`) | backend |
| `Mapper/` | Entity → output DTO (`TrackMapper::toView(Track, ?User $viewer)`), batch-loads viewer flags (`likedByMe`…) to avoid N+1 | backend |
| `Security/Voter/` | `TrackVoter` (VIEW, EDIT, CLIP, STREAM), `PlaylistVoter`, `PostVoter`, `CommentVoter`, `ArtistVoter` | backend |
| `Pagination/` | `Cursor`, `CursorCodec`, `CursorPage<T>` | backend |
| `Problem/` | `ProblemCode` enum, `ApiProblemException`, problem normalizer | backend |
| `Storage/` | `ObjectStorage` interface + `FlysystemObjectStorage` | backend |
| `Stream/` | `StreamTokenSigner`, stream controller | backend |
| `Message/` | Messenger messages (shared contract, §8) | backend |
| `MessageHandler/` | Handlers for non-media messages | backend |
| `Media/` | ffprobe/ffmpeg wrappers + media message handlers | media-infra |
| `Feed/` | `FeedRanker` + `SqlFeedRanker` | backend |
| `Search/` | `SearchProvider` + `PostgresSearchProvider` | backend |
| `Recommendation/` | affinity + trending computation | backend |
| `RateLimit/` | limiter listener mapping route → limiter | backend |
| `DataFixtures/` | Foundry/fixtures, generated-audio seeds | media-infra |

- API Platform: `formats: json` only, `patch_formats: json + merge-patch+json`, `error_formats: problem+json`, Hydra and JSON-LD disabled, docs (`/api/docs`) disabled outside dev, `route_prefix: /api/v1`. Custom controllers only for `/stream/{token}` and `/auth/*` (gesdinet/lexik).
- Visibility: providers resolve "can the viewer see it" and throw `NotFound` (404) themselves; voters guard mutations (403). Never leak existence through 403.
- Verified-email gate: operations flagged `x-requires-verified-email` in `openapi.yaml` declare `security: "is_granted('ROLE_USER') and is_granted('EMAIL_VERIFIED')"`; `EmailVerifiedVoter` grants when `emailVerifiedAt !== null`; a denial on that attribute is rendered as 403 `email_not_verified` (not `forbidden`).
- Account tokens: `AccountTokenIssuer::issue(User, AccountTokenPurpose): string` (returns the raw token, stores only its SHA-256) and `consume(string $raw, AccountTokenPurpose): User` (throws `account_token_invalid`). Raw tokens exist only in the handler that sends the email.
- Counters: repository methods `incrementX(id, delta)` issuing DQL `UPDATE`. Never `$entity->setCount($entity->getCount()+1)`.
- Transactions: processors that touch counters run in `EntityManager::wrapInTransaction`. Messages are dispatched **inside** that transaction: the Doctrine transport shares the DBAL connection, so the message row commits atomically with the data (outbox for free) and a worker never sees an uncommitted entity. Do not give the transport its own connection.
- Tests: `tests/Unit`, `tests/Functional` (ApiTestCase, real Postgres), `tests/Security` (qa-security). Test DB reset with DAMA DoctrineTestBundle.

## 3. Frontend (TS)

```
src/
  api/            client.ts (fetch wrapper, refresh single-flight), schema.d.ts (generated), queries/<domain>.ts (TanStack hooks)
  features/<domain>/   components + hooks per domain: auth, profile, artists, tracks, player, playlists, feed, posts, search, moderation
  components/ui/  shared primitives
  stores/         Zustand stores (player.ts, session.ts)
  routes/         route modules (React Router)
  mocks/          MSW handlers + fixtures (from openapi.yaml)
  lib/            pure helpers (time, format)
```

- Types generated by `openapi-typescript docs/openapi.yaml -o src/api/schema.d.ts` (`npm run gen:api`); never hand-write API types. CI fails if the generated file is stale.
- Files: components `PascalCase.tsx`, hooks `useThing.ts`, others `camelCase.ts`; tests next to file `*.test.ts(x)`. Named exports only.
- Query keys: `[domain, ...params]` e.g. `['track', id]`, `['user', username, 'tracks']`.
- Access token kept in memory only (Zustand session store), never in localStorage. Web relies on the cookie for refresh: `credentials: 'include'` on `/auth/*` only.
- On 401 `token_expired`: one shared refresh promise, then replay. On refresh failure → logout state.

## 4. Wire format

- JSON camelCase; enums lowercase snake values; booleans `isX`/`hasX`/`xByMe`/`canX`.
- Dates ISO 8601 UTC with `Z`, second precision (`Y-m-d\TH:i:s\Z`). Durations in **ms** (`durationMs`), sizes in bytes.
- Ids: UUID v7 lowercase canonical string. Path identifiers: `username` (users), `slug` (artists), `name` (hashtags), uuid otherwise.
- Media URLs: absolute, built from `MEDIA_PUBLIC_BASE_URL` + key. Stream URLs absolute from `APP_PUBLIC_URL`.
- Null fields are present with `null` (never omitted), except mobile-only `refreshToken*` and search sections.

## 5. Errors

RFC 7807, `Content-Type: application/problem+json`:
```json
{"type":"urn:wave:problem:validation_failed","title":"Validation failed","status":422,"code":"validation_failed",
 "detail":"…","violations":[{"propertyPath":"username","message":"…","code":"…"}]}
```
- `code` list = `ProblemCode` in `openapi.yaml` (single source; PHP enum mirrors it 1:1). Adding a code = contract change.
- Business errors: `throw new ApiProblemException(ProblemCode::ClipsNotAllowed, detail: '…')`; status derived from the code.
- 500 → `internal_error`, no stack trace or exception message outside `dev`.
- 413 above 32 MB is a bare nginx response: clients treat any 413 as `payload_too_large`.

## 6. Pagination (ADR 002)

- Request `?cursor=&limit=`; response `{ "items": [...], "nextCursor": "…" | null }`. No total counts.
- Cursor = `base64url(json)` of the keyset of the last item + HMAC-SHA256 (first 16 bytes, key `APP_SECRET`) to reject tampering → 400 `invalid_cursor`. Example payload: `{"v":1,"k":["2026-10-24T08:15:30.123456Z","0192…"]}`.
- Sort keys always end with `id` as tiebreaker. Fetch `limit + 1` rows to know if there is a next page.
- Exceptions: search (offset in cursor, capped at 200), for-you (ranker cursor, ADR 005), playlist items (`position`).

## 7. Shared PHP interfaces

```php
namespace App\Storage;

enum StorageArea: string { case Private = 'private'; case Public = 'public'; }

interface ObjectStorage
{
    /** @param resource $stream */
    public function write(StorageArea $area, string $key, $stream, string $contentType): void;
    /** @return resource */
    public function readStream(StorageArea $area, string $key);
    /** Downloads to a local temp file for ffmpeg; caller deletes it. */
    public function downloadToTemp(StorageArea $area, string $key): string;
    public function exists(StorageArea $area, string $key): bool;
    public function size(StorageArea $area, string $key): int;
    /** Idempotent: missing key is not an error. */
    public function delete(StorageArea $area, string $key): void;
    /** Public area only: absolute URL (MEDIA_PUBLIC_BASE_URL/key). */
    public function publicUrl(string $key): string;
    /** Private area only: nginx internal path for X-Accel-Redirect, e.g. /_protected/private/audio/tracks/{id}.m4a */
    public function internalRedirectPath(string $key): string;
}

namespace App\Feed;

interface FeedRanker
{
    /** Post ids in display order; all ids must be playable for $viewerId at call time. */
    public function forYou(Uuid $viewerId, ?string $cursor, int $limit): RankedPage;
}
final readonly class RankedPage
{
    /** @param list<Uuid> $postIds */
    public function __construct(public array $postIds, public ?string $nextCursor) {}
}

namespace App\Search;

enum SearchType: string { case Tracks = 'tracks'; case Artists = 'artists'; case Users = 'users'; case Playlists = 'playlists'; case Hashtags = 'hashtags'; }

interface SearchProvider
{
    /** Ids ordered by relevance, already filtered by visibility for $viewerId. */
    public function search(string $query, SearchType $type, Uuid $viewerId, int $offset, int $limit): SearchHits;
}
final readonly class SearchHits
{
    /** @param list<Uuid> $ids  @param int|null $nextOffset null = no more */
    public function __construct(public array $ids, public ?int $nextOffset) {}
}
```
`ObjectStorage` has no listing method on purpose. Listing quarantine objects (only `CleanupQuarantine` needs it) goes through `App\Media\QuarantineScanner` (interface + `FlysystemQuarantineScanner`, owned by media-infra) and must not leak into backend code.

Implementations return ids only; providers hydrate and map (keeps CF/embeddings/Meilisearch swaps cheap). Cursors are opaque strings owned by the implementation (signed with the same codec as §6).

## 8. Messenger

Transports (Doctrine): `media` (ffmpeg jobs, retry 2× ×4 delay 10 s), `async` (everything else, retry 3×), `failed`. Scheduler: `RecurringMessage`s in `App\Schedule\WaveSchedule` (backend).
Consumers (ADR 006): service `worker` consumes `media` only (2 replicas, 1G each); service `worker-async` consumes `async` + `scheduler_default` (1 replica, 512M — the scheduler must run in exactly one process).
Messages are `final readonly` in `App\Message`, scalar payloads only (ids as RFC 4122 strings), never entities.

| Message | Payload | Transport | Dispatched by | Handler owner | Effect |
|---|---|---|---|---|---|
| `ProcessTrack` | `trackId` | media | backend (upload processor) | media-infra | ffprobe validate (audio stream, codec mp3/aac, ≤ 600 s, size) → loudnorm 2-pass → `audio/tracks/{id}.m4a` → `Track::markReady(audioKey, durationMs)` or `markFailed(FailureReason)`; delete quarantine on success |
| `ProcessImage` | `target` (`user_avatar`\|`artist_avatar`\|`track_cover`), `targetId`, `quarantineKey` | media | backend (avatar/cover processors) | media-infra | validate + resize to WebP (DATA_MODEL §14), set key on entity via `setAvatarKey/setCoverKey`, dispatch `PurgeObjects` for the old key; invalid → drop silently, log |
| `GenerateClip` | `postId` | media | backend (post processor) | media-infra | cut processed track audio → `audio/clips/{postId}.m4a` → `Post::setClipKey`, then ready-transition SQL (DATA_MODEL §9) |
| `ProcessPostVisual` | `postId` | media | backend (post processor, only if visual) | media-infra | validate image/video (ffprobe; video ≤ 60 s, strip audio) → public keys → `Post::setVisual(key, posterKey)`, then ready-transition SQL |
| `PurgeObjects` | `area`, `keys: list<string>` | async | backend (deletes, replacements) and media-infra | media-infra | `ObjectStorage::delete` each, idempotent |
| `CleanupQuarantine` | — (scheduled daily 03:30 UTC) | async | Scheduler | media-infra | delete quarantine objects of failed items older than 7 days, and orphans older than 24 h |
| `SendVerificationEmail` | `userId` | async | backend (register, resend) | backend | skip if user gone or verified; issue token (24 h), send `email/verify_email` |
| `SendPasswordResetEmail` | `email` (normalized) | async | backend (`POST /auth/password-reset`, always) | backend | no-op if no user / suspended; issue token (1 h), send `email/password_reset` |
| `SendAccountDeletedEmail` | `email`, `displayName` | async | backend (`DELETE /me`) | backend | send `email/account_deleted` |
| `PurgeAccountTokens` | — (scheduled daily 03:00 UTC) | async | Scheduler | backend | delete `account_token` rows older than 7 days |
| `RecomputeAffinity` | `userId` | async | backend on like/counted listen/completed view, with `DeduplicateStamp("affinity-{userId}", 300 s)` | backend | rewrite `user_affinity` for the user (ADR 005) |
| `RecomputeAffinityAll` | — (scheduled daily 04:00 UTC) | async | Scheduler | backend | dispatch `RecomputeAffinity` for users active in last 30 days |
| `RecomputeTrending` | — (scheduled every 15 min) | async | Scheduler | backend | recompute `track.trending_score`, `post.trending_score` (ADR 005) |

Email: Symfony Mailer called **synchronously inside these handlers** (do not also route `SendEmailMessage` to a transport); Twig templates `templates/email/<name>.html.twig` + `.txt.twig`, English, links built from `FRONT_PUBLIC_URL` (`/verify-email?token=…`, `/reset-password?token=…`). Front pages read the token, `history.replaceState` it out of the URL, then POST it; they set `Referrer-Policy: no-referrer`.

Entity mutators used by media handlers are part of the contract (backend implements, media-infra calls): `Track::markReady(string $audioKey, int $durationMs)`, `Track::markFailed(FailureReason)`, `Track::setCoverKey(?string)`, `User::setAvatarKey(?string)`, `Artist::setAvatarKey(?string)`, `Post::setClipKey(string)`, `Post::setVisual(string $key, ?string $posterKey)`, `Post::markFailed(FailureReason)`, and `PostRepository::tryMarkReady(Uuid): bool` (the ready-transition SQL). `markReady` also triggers `ArtistRepository::recountTracks(artistId)`.
Handlers must be idempotent (re-delivery): skip if the entity is gone or no longer `processing`. Validation failures throw `UnrecoverableMessageHandlingException` after marking failed.

## 10. Git

- Conventional Commits: `type(scope): imperative summary` — types `feat fix refactor perf test docs build ci chore`; scopes `api auth media feed search player front infra docs security`. Body explains *why*; reference ticket `Refs: W-12`.
- One commit per feature/ticket. Authored by the user only. **No `Co-Authored-By` or any AI trailer.** Agents never commit: the lead does.
- Never commit `.env`, keys (`config/jwt/*.pem`), media files, or generated `schema.d.ts` drift.
